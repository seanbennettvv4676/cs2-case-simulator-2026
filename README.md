## About the Simulator

CS2 Oteviraci Simulator is an HTML-based web project that recreates a Counter-Strike 2 case-opening flow inside a browser. Its navigation is arranged as a simple sequence: start on the homepage, enter the case section, and then review the collection area.

The simulator keeps its presentation compact and avoids requiring a complex setup. In addition to standard browser interaction, it includes keyboard controls for a more direct way to move through supported actions. The project is intended to run as a straightforward web experience rather than as a native application.
